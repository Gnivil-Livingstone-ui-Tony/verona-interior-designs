# VERONA Interior Designs

A web-based portfolio and business website for VERONA Interior Designs, showcasing interior design services and projects while allowing customers to submit enquiries online.

## About the Project

VERONA Interior Designs is a PHP-based web application developed to establish an online presence for an interior design business. The website presents services, displays completed projects, and provides a contact form for customer enquiries.

## Features

- Responsive homepage and navigation
- Interior design services page
- Project gallery
- Customer enquiry and contact form
- WhatsApp contact integration
- PHP and MySQL database integration
- Administrative dashboard for managing website information and enquiries

## Services

- Ceiling Board Designs
- Modern Kitchen Design
- Interior Decoration
- House Interior Finishing
- Other Enquiries

## Technologies Used

- PHP
- MySQL
- HTML5

- Git and GitHub for version control

## Project Structure

The project contains PHP pages, styling files, scripts, images, database connection logic, and administrative functionality.

Sensitive configuration files and database credentials should not be committed to the repository.

## Installation and Setup

1. Install XAMPP.
2. Clone or download this repository into the `htdocs` directory.
3. Create a MySQL database for the project.
4. Configure the database connection using your own local credentials.
5. Import the required database tables.
6. Start Apache and MySQL.
7. Open the project through `http://localhost/verona/`.

## Security Notes

- Keep database credentials out of public repositories.
- Do not commit passwords, private configuration files, or production database exports.
- Use secure password hashing for administrator accounts.
- Validate and sanitize user input.
